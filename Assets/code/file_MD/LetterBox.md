# 📦 LetterBox.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ควบคุม **ระบบกล่องสุ่ม / ถุงวัตถุดิบ (Generic Letter Box)** บนทางวิ่ง เคลื่อนที่จากขวาไปซ้ายด้วย `ScrollLeft` ทำหน้าที่เป็นตัวแทนไอเทมดรอปตัวอักษรแบบโมเดลรวมชิ้นเดียว (Single 3D Prefab เช่น กล่องสมบัติ, ถุงผ้า หรือผลึกอัญมณี) แทนการสร้างโมเดลตัวอักษร 3D รายตัว A–Z ช่วยประหยัด Asset ในโปรเจกต์ได้อย่างเด็ดขาด และส่งต่อการสุ่มตัวอักษรไปยัง `LetterDropManager` (Smart Drop System) เบื้องหลังเมื่อผู้เล่นวิ่งชน

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **Single Prefab Asset Efficiency (แก้ปัญหาเรื่อง Asset):**
   - ใช้โมเดล 3D เพียงชิ้นเดียวทั้งเกมสำหรับไอเทมตัวอักษร ไม่ต้องสร้างโมเดลตัวอักษร 26 ตัว A–Z
   - ตัดความซับซ้อนของการจับคู่โมเดลตัวอักษรในฉาก
2. **เลื่อนอัตโนมัติด้วย ScrollLeft (`[RequireComponent(typeof(ScrollLeft))]`):**
   - มีการผูก `ScrollLeft` อัตโนมัติ ทำให้กล่องเลื่อนมาจากทางขวาตามความเร็วของด่าน และลบตัวเองทิ้งอัตโนมัติเมื่อพ้นขอบจอทางซ้าย
3. **อนิเมชันหมุน 3D และลอยขึ้นลง (3D Rotation & Bobbing Effect):**
   - หมุนรอบตัวเองแบบ 360 องศาตลอดเวลาตามความเร็ว `rotateSpeed`
   - มีระบบ `enableBobbing` ลอยกระเพื่อมขึ้นลงเบาๆ ด้วยตรีโกณมิติ `Mathf.Sin` ช่วยให้กล่องดูน่าสนใจ ดึงดูดสายตา และไม่จมไปกับพื้น
4. **Trigger Detection & Softlock Prevention:**
   - ใช้ `Collider (Is Trigger)` ตรวจจับผู้เล่น (`Tag: Player`)
   - มีระบบป้องกันการตรวจจับซ้ำซ้อนในเฟรมเดียวกัน (`isCollected` flag และสั่งปิด Collider ทันที)
   - ส่งข้อมูลไปยัง `LetterDropManager.Instance.ProcessLetterBoxPickup()` เพื่อคำนวณสุ่มตัวอักษรที่การันตีไม่ให้เกิดปัญหา Softlock ตอนสู้บอส
   - มีระบบ Fallback ปลอดภัยในกรณีที่ไม่มี Manager ในฉาก

## 📋 ตัวแปรใน Inspector (Inspector Settings)

| ตัวแปร | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `visualModel` | `Transform` | - | Transform หรือโมเดล 3D ของกล่อง/ถุงที่จะให้หมุนและลอย |
| `rotateSpeed` | `float` | `75.0` | ความเร็วในการหมุนรอบแกน Y (องศาต่อวินาที) |

| `bobSpeed` | `float` | `3.5` | ความถี่ในการลอยขึ้นลง |
| `bobHeight` | `float` | `0.2` | ระยะความสูงในการลอยขึ้นลง |

## 💡 แนวทางการติดตั้งใน Unity (Setup Guide)

1. นำโมเดล 3D ของกล่องสมบัติ, ถุงผ้า หรือผลึกอัญมณีมาสร้างเป็น Prefab ตั้งชื่อว่า `LetterBox_Prefab`
2. ใส่คอมโพเนนต์ `BoxCollider` หรือ `SphereCollider` แล้วติ๊กถูกที่ช่อง **`Is Trigger`**
3. แปะสคริปต์ `LetterBox.cs` (Unity จะเพิ่ม `ScrollLeft` และตั้งค่า Trigger ให้อัตโนมัติ)
4. ลากโมเดลลูกใส่ในช่อง `Visual Model` เพื่อให้หมุนสวยงาม
5. นำ Prefab นี้ไปใส่ในช่อง `letterBoxPrefab` ของ `SpawnManager` ในฉาก
