# 🏃‍♂️ PlayerController.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ควบคุมตัวละครหลักสไตล์ **Cookie Run** สำหรับ Unity 3D ในรูปแบบ **วิ่งอยู่กับที่ (Stationary Runner)** โดยให้ฉากและสิ่งกีดขวางเลื่อนเข้าหาตัวละคร ได้รับการปรับปรุงฟิสิกส์การกระโดดให้ **กระชับ รวดเร็ว ตกแตะพื้นไว (Snappy Jump & Fast Fall)** ไม่ลอยค้างในอากาศนานเกินไป รีเซ็ตสิทธิ์การกระโดดได้ทันท่วงที พร้อมท่ากดสไลด์กลางอากาศทิ้งตัวดิ่งลงพื้น (Mid-Air Slide Fast-Fall), ระบบ Jump Buffering & Coyote Time และระบบรองรับการตกเหวในอนาคต (Pit Death)

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **Cookie Run Snappy Jump Physics (ฟิสิกส์กระโดดกระชับ ไม่ลอยเคว้ง):**
   - **Upward Gravity Multiplier (`2.8x`):** แรงโน้มถ่วงตอนพุ่งขึ้นมีความกระชับ ตัวละครพุ่งขึ้นอย่างมีน้ำหนัก
   - **Fall Gravity Multiplier (`4.5x`):** เมื่อถึงจุดสูงสุดแล้วเริ่มตกลงมา (`velocity.y < 0`) ระบบจะเร่งแรงโน้มถ่วงเพิ่มขึ้นอย่างมาก ทำให้ตัวละครดิ่งแตะพื้นอย่างรวดเร็ว จบรอบกระโดดได้ไว รีเซ็ตรอบกระโดดถัดไปได้ทันที
   - **Low Jump Control (`3.5x`):** หากผู้เล่นปล่อยปุ่มกระโดดเร็ว ตัวละครจะตัดแรงส่งทันที ทำให้ควบคุมความสูงของกระโดดได้ดั่งใจ
2. **Double Jump & Zero Latency Reset:**
   - เมื่อกดกระโดดครั้งที่สองกลางอากาศ ระบบจะตัดแรงเฉื่อยดิ่งเดิมออกทันที และใส่แรงส่ง `doubleJumpForce` ขึ้นใหม่ ให้ความรู้สึกสะใจ คล่องตัว และแม่นยำ
3. **Mid-Air Slide Fast-Fall (ท่าทิ้งตัวลงพื้นกลางอากาศแบบ Cookie Run):**
   - หากผู้เล่นกดปุ่มสไลด์ (`S`, `DownArrow`, `Ctrl`) ขณะอยู่กลางอากาศ ตัวละครจะเร่งความเร็วดิ่งลงสู่พื้นทันที (`airSlideFastFallSpeed = 16f`) ช่วยให้ผู้เล่นเซียนสามารถยกเลิกการลอยตัวกลางอากาศเพื่อกดย่อตัวมุดลอดอุปสรรคได้อย่างฉับไว
4. **Jump Buffering & Coyote Time:**
   - **Jump Buffer (`0.15s`):** หากผู้เล่นกดปุ่มกระโดดล่วงหน้าก่อนเท้าแตะพื้น 0.15 วินาที ตัวละครจะกระโดดให้อัตโนมัติทันทีที่เท้าแตะพื้น ไม่เกิดอาการกดไม่ติด
   - **Coyote Time (`0.12s`):** ช่วยให้กดกระโดดได้แม้หลุดจากขอบพื้นไปแล้วเสี้ยววินาที
5. **Immediate Ground Check:**
   - ใช้การตรวจจับพื้นแบบสองชั้น: ทั้ง Raycast ใต้ฝ่าเท้า และ Contact Normal จากฟิสิกส์ เพื่อให้ `jumpCount = 0` และ `isGrounded = true` ทันทีที่แตะพื้น
6. **Hold-to-Duck / Slide (ย่อตัวสไลด์แนบพื้น 100%):**
   - ย่อทั้ง Collider และ Scale โมเดลโดยคำนวณฐานเท้าให้อยู่แนบพื้นเสมอ ไม่ลอย
7. **Pit / Fall Death Support (ระบบตกเหว):**
   - ตรวจจับระดับความสูง `pitDeathThresholdY` (เช่น Y < -5.0m) หากตกลงไปจะยิง Event `OnPlayerFellIntoPit` และเข้าสู่สถานะตาย (`Die()`) ทันที

## 📡 Events & Delegation

- `public event Action<int> OnHealthChanged;` : แจ้งเตือนเมื่อพลังชีวิตหัวใจเปลี่ยนแปลง
- `public event Action OnPlayerDied;` : แจ้งเตือนเมื่อเลือดหมดหรือตัวละครเสียชีวิต
- `public event Action OnPlayerFellIntoPit;` : แจ้งเตือนเมื่อตัวละครตกลงสู่เหว
