# 🔤 CollectibleLetter.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ควบคุมเหรียญและโมเดลตัวอักษร 3D บนเส้นทางวิ่ง เคลื่อนที่จากขวาไปซ้ายด้วย `ScrollLeft` ทำหน้าที่แสดงผลตัวอักษร 3D หมุนและลอยขึ้นลงแบบมีอนิเมชั่น (Bobbing Effect) ให้ผู้เล่นเห็นได้เด่นชัด และส่งตัวอักษรภาษาอังกฤษเข้าสู่กระเป๋า (`LetterInventory`) เมื่อผู้เล่นวิ่งชน

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **อัตโนมัติด้วย ScrollLeft (`[RequireComponent(typeof(ScrollLeft))]`):**
   - มีการผูก `ScrollLeft` อัตโนมัติ ทำให้เหรียญตัวอักษรลอยมาจากทางขวา และลบตัวเองทิ้งอัตโนมัติเมื่อพ้นจอทางซ้าย
2. **รองรับโมเดล 3D และอนิเมชันหมุน (3D Visuals & Rotation):**
   - มีช่อง `visualModel` สำหรับผูกโมเดล 3D ของตัวอักษร (หากเว้นว่างไว้จะหมุนตัวแม่ทั้งหมด)
   - หมุนรอบตัวเองแบบ 360 องศาตลอดเวลาตามความเร็ว `rotateSpeed`
3. **เอฟเฟกต์ลอยขึ้นลงให้เห็นชัดเจน (Bobbing Effect):**
   - มีระบบ `enableBobbing` คำนวณความสูงด้วยฟังก์ชันตรีโกณมิติ `Mathf.Sin(Time.time * bobSpeed) * bobHeight` ทำให้โมเดล 3D ลอยกระเพื่อมขึ้นลงนุ่มนวล สะดุดตา และไม่กลืนไปกับพื้น
4. **ค้นหา TextMeshPro 3D อัตโนมัติ:**
   - หากมี TextMeshPro ในลูก จะค้นหาและจับคู่ให้อัตโนมัติ และอัปเดตตัวอักษรทันทีผ่าน `SetLetter(char)`
5. **การเก็บไอเทม (Collection Logic):**
   - ใช้ `OnTriggerEnter(Collider other)` เมื่อชนผู้เล่น (`other.CompareTag("Player")`) จะส่งตัวอักษรเข้า `LetterInventory.AddLetter(letter)` และทำลายตัวเองทิ้งทันที

## 📋 ตัวแปรใน Inspector (Inspector Settings)

| ตัวแปร | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `letter` | `char` | `'A'` | ตัวอักษรภาษาอังกฤษที่เหรียญนี้มอบให้ (A-Z) |
| `textMesh` | `TMP_Text` | - | TextMeshPro 3D สำหรับแสดงตัวอักษร (จะหาจากลูกให้อัตโนมัติหากไม่ได้ลากใส่) |
| `visualModel` | `Transform` | - | Transform หรือโมเดล 3D ของตัวอักษรที่จะให้หมุนและลอย |
| `rotateSpeed` | `float` | `90.0` | ความเร็วในการหมุนรอบแกน Y (องศาต่อวินาที) |
| `enableBobbing` | `bool` | `true` | เปิด/ปิดเอฟเฟกต์ลอยขึ้นลงเบาๆ ให้เห็นเด่นชัด |
| `bobSpeed` | `float` | `3.0` | ความถี่ในการลอยขึ้นลง |
| `bobHeight` | `float` | `0.25` | ระยะความสูงในการลอยขึ้นลง |

## 💡 แนวทางการติดตั้งใน Unity (Setup Guide)

1. สร้าง Prefab ตัวอักษร (เช่น นำโมเดล 3D ตัวอักษร หรือป้าย 3D Text มาใช้)
2. เพิ่ม `Collider` และติ๊กถูกที่ช่อง **`Is Trigger`**
3. แปะสคริปต์ `CollectibleLetter.cs` (Unity จะเพิ่ม `ScrollLeft` ให้โดยอัตโนมัติ)
4. ลากโมเดล 3D ตัวอักษรใส่ช่อง `Visual Model` เพื่อให้หมุนและลอยขึ้นลงอย่างสวยงาม
