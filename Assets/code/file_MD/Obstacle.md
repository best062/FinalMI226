# 🚧 Obstacle.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ควบคุมวัตถุสิ่งกีดขวาง (Obstacles) บนเส้นทางวิ่ง แบ่งออกเป็น **3 หมวดการควบคุมชัดเจน: 1.กระโดด 1 ครั้ง, 2.กระโดด 2 ครั้ง, และ 3.สไลด์** เคลื่อนที่จากขวาไปซ้ายร่วมกับ `ScrollLeft` ตรวจจับการชนกับตัวละครผู้เล่น (Player) และสร้างความเสียหายลดหัวใจ พร้อมรองรับการแสดงผล Gizmo สีใน Unity Scene View

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **ระบบประเภทสิ่งกีดขวางแบ่ง 3 ส่วน (3-Part Obstacle System):**
   - **`SingleJump (1. กระโดด 1 ครั้ง):`** สิ่งกีดขวางระดับพื้นดินเตี้ย เช่น ก้อนหินเล็ก, พุ่มหนามเตี้ย, ขอนไม้บนพื้น -> ผู้เล่นกดกระโดดเพียงครั้งเดียวก็พ้น
   - **`DoubleJump (2. กระโดด 2 ครั้ง):`** สิ่งกีดขวางระดับพื้นที่มีความสูงหรือกว้างขึ้น เช่น กำแพงหิน, เสาสูง, กล่องซ้อนสองชั้น -> ผู้เล่นต้องใช้ท่า **Double Jump** (กระโดด 2 จังหวะ) เพื่อเพิ่มแรงส่งให้ข้ามพ้น
   - **`Slide (3. สไลด์ลอด):`** สิ่งกีดขวางระดับสูงลอยฟ้า เช่น คานไม้ลอย, กิ่งไม้ขวางระดับศีรษะ, ผลึกหินย้อย ด้านล่างเปิดโล่ง -> ผู้เล่นต้องกดปุ่มย่อตัวเพื่อ **สไลด์มุดลอด (Hold-to-Duck)**
   - *(รองรับ `Low` และ `High` เดิมแบบ Backwards Compatibility)*
2. **ขับเคลื่อนด้วย ScrollLeft อัตโนมัติ (`[RequireComponent(typeof(ScrollLeft))]`):**
   - สิ่งกีดขวางจะเลื่อนจากขวามาซ้ายตามความเร็วของด่าน และลบตัวเองทิ้งอัตโนมัติเมื่อพ้นขอบจอทางซ้าย
3. **การตรวจจับการชนและดาเมจ (Collision & Damage):**
   - ใช้ `OnTriggerEnter(Collider other)` เมื่อชนผู้เล่น (`Tag: Player`) จะสั่ง `player.TakeDamage(damageAmount)`
   - รองรับการเล่นเสียง (`hitSoundClip`) และ Particle Effect (`hitParticlePrefab`)
4. **Scene View Visual Gizmos:**
   - วาดโครงเส้น Wireframe Cube สีใน Scene View เพื่อให้นักพัฒนาแยกแยะชนิดของอุปสรรคได้ทันที:
     - 🟢 **สีเขียว:** กระโดด 1 ครั้ง (`SingleJump`)
     - 🟡 **สีเหลือง:** กระโดด 2 ครั้ง (`DoubleJump`)
     - 🔵 **สีฟ้า:** สไลด์ลอด (`Slide`)

## 📋 ตัวแปรใน Inspector (Inspector Settings)

| ตัวแปร | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `obstacleType` | `ObstacleType` | `SingleJump` | ประเภทสิ่งกีดขวาง (`SingleJump`, `DoubleJump`, `Slide`) |
| `damageAmount` | `int` | `1` | จำนวนดาเมจหัวใจที่หักเมื่อชน (ปกติ 1 หัวใจ) |
| `hitParticlePrefab` | `GameObject` | - | เอฟเฟกต์ระเบิด/อนุภาคเมื่อชน (Optional) |
| `hitSoundClip` | `AudioClip` | - | เสียงเอฟเฟกต์เมื่อผู้เล่นชน (Optional) |

## 💡 แนวทางการติดตั้งใน Unity (Setup Guide)

1. สร้าง Prefab สิ่งกีดขวาง (เช่น หิน, เสา, หรือท่อนไม้)
2. เพิ่ม `Collider` (เช่น BoxCollider) และติ๊กถูกที่ช่อง **`Is Trigger`**
3. แปะสคริปต์ `Obstacle.cs` (Unity จะผูก `ScrollLeft` ให้อัตโนมัติ)
4. เลือกประเภทในช่อง `Obstacle Type` ให้ตรงกับลักษณะการหลบหลีก (1.กระโดด 1 ครั้ง / 2.กระโดด 2 ครั้ง / 3.สไลด์)
