# 🚧 Obstacle.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ควบคุมวัตถุสิ่งกีดขวาง (Obstacles) บนเส้นทางวิ่ง ทำหน้าที่เคลื่อนที่จากขวาไปซ้ายร่วมกับคอมโพเนนต์ `ScrollLeft` ตรวจจับการชนกับตัวละครผู้เล่น (Player) และสร้างความเสียหาย (1 หัวใจ)

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **อัตโนมัติด้วย ScrollLeft (`[RequireComponent(typeof(ScrollLeft))]`):**
   - เมื่อเพิ่มสคริปต์ `Obstacle` ให้กับวัตถุ ระบบจะผูกคอมโพเนนต์ `ScrollLeft` มาด้วยอัตโนมัติ ทำให้สิ่งกีดขวางเคลื่อนที่จากขวามาซ้าย และลบทิ้งอัตโนมัติเมื่อพ้นจอทางซ้าย
2. **ประเภทสิ่งกีดขวาง (Obstacle Types):**
   - มีการกำหนด Enum `ObstacleType` เพื่อแยกชนิดการหลบหลีก:
     - **`Low`:** สิ่งกีดขวางระดับพื้นดิน เช่น ก้อนหิน, พุ่มหนาม, ท่อนไม้บนพื้น -> ผู้เล่นต้อง **กระโดด (Jump)** ข้าม
     - **`High`:** สิ่งกีดขวางระดับศีรษะ/ลอย เช่น ท่อนไม้สูง, ซุ้มหินเตี้ย -> ผู้เล่นต้อง **กดย่อตัวสไลด์ (Hold-to-Duck)** ลอดใต้
3. **การตรวจจับการชน (Collision Detection):**
   - ใช้ `OnTriggerEnter(Collider other)` โดยอ็อบเจกต์สิ่งกีดขวางต้องตั้งค่า Collider เป็น `Is Trigger = true`
   - ตรวจสอบ Tag ของผู้เล่นด้วย `other.CompareTag("Player")`
   - เมื่อชนผู้เล่น จะดึงคอมโพเนนต์ `PlayerController` และสั่ง `player.TakeDamage(damageAmount)`

| `damageAmount` | `int` | `1` | ปริมาณดาเมจหัวใจที่สร้างเมื่อชน (ปกติคือ 1 ดวง) |

## 💡 แนวทางการติดตั้งใน Unity (Setup Guide)

1. สร้าง Prefab สิ่งกีดขวาง (เช่น ก้อนหิน หรือ ท่อนไม้)
2. เพิ่ม `Collider` (เช่น BoxCollider) และติ๊กถูกที่ช่อง **`Is Trigger`**
3. แปะสคริปต์ `Obstacle.cs` (Unity จะเพิ่ม `ScrollLeft` ให้โดยอัตโนมัติ)
4. เลือกระดับความสูง `obstacleType` ให้สัมพันธ์กับตำแหน่งของโมเดล
