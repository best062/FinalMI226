# 🎒 LetterInventory.cs

## 📌 บทสรุปสั้น (Summary)
สคริปต์ระบบกระเป๋าจัดเก็บตัวอักษรภาษาอังกฤษ (Letter Inventory) ที่ผู้เล่นเก็บได้ระหว่างวิ่ง ทำหน้าที่นับจำนวนตัวอักษรแต่ละตัวแบบ Key-Value ตรวจสอบว่ามีตัวอักษรครบตามที่คำศัพท์เป้าหมายของบอสต้องการหรือไม่ และตัดตัวอักษรออกจากกระเป๋าเมื่อสะกดคำเพื่อโจมตีบอส

---

## ⚙️ คุณสมบัติหลัก (Key Features)

1. **โครงสร้างจัดเก็บข้อมูล (Data Structure):**
   - ใช้ `Dictionary<char, int>` (เช่น `'L' => 2, 'I' => 1, 'O' => 3, 'N' => 1`) เพื่อให้บันทึกและค้นหาความถี่ของตัวอักษรได้อย่างรวดเร็วและมีประสิทธิภาพสูง
2. **การเพิ่มตัวอักษร (AddLetter):**
   - แปลงตัวอักษรเป็นพิมพ์ใหญ่ (`char.ToUpper`)
   - หากมีตัวอักษรนั้นอยู่แล้ว จะเพิ่มจำนวน (`+1`) หากยังไม่มี จะเพิ่ม Key ใหม่ด้วยค่าเริ่มต้นเป็น `1`
   - ส่งสัญญาณผ่าน Event `OnInventoryChanged` เพื่อให้ UI แสดงผลตัวอักษรในกระเป๋าอัปเดตแบบ Realtime
3. **การตรวจสอบความพร้อมสะกดคำ (CanFormWord):**
   - รับคำศัพท์เป้าหมาย (เช่น `"LION"`)
   - นับตัวอักษรที่ต้องใช้ทั้งหมด แล้วนำไปเปรียบเทียบกับตัวอักษรที่มีในกระเป๋า
   - คืนค่า `true` หากในกระเป๋ามีตัวอักษรครบถ้วนตามที่คำนั้นต้องการ และคืนค่า `false` หากตัวอักษรใดตัวอักษรหนึ่งไม่เพียงพอ
4. **การใช้ตัวอักษร (ConsumeWord):**
   - เมื่อผู้เล่นสะกดคำสำเร็จและคำสั่งโจมตีบอสถูกเรียก
   - จะหักลบจำนวนตัวอักษรที่ใช้ไปจริงออกจากกระเป๋า หากเหลือ 0 จะลบ Key นั้นออกจาก Dictionary
   - ส่งสัญญาณผ่าน Event `OnInventoryChanged` เพื่อให้ UI ล้างหรืออัปเดตตัวอักษรที่ถูกใช้ไป

---

## 📡 Events & Delegation

- `public event Action<Dictionary<char, int>> OnInventoryChanged;` : ส่งโครงสร้างคลังตัวอักษรทั้งหมดออกไปให้ UI วาดการแสดงผล (เช่น แถบแสดงตัวอักษรที่มีบนหน้าจอ HUD)

---

## 🧪 ตัวอย่างการทำงาน (Code Logic Flow)

```
[ผู้เล่นเก็บเหรียญ 'L', 'I', 'O', 'N'] 
       ⬇
Inventory เก็บ: { 'L':1, 'I':1, 'O':1, 'N':1 }
       ⬇
บอสต้องการคำว่า: "LION"
       ⬇
CanFormWord("LION") -> เช็คพบว่ามีครบ -> คืนค่า true
       ⬇
ConsumeWord("LION") -> ตัด L, I, O, N ออกจากกระเป๋า -> เรียกบอสรับความเสียหาย
```
